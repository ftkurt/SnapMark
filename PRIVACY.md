# Privacy

SnapMark is designed to keep screenshots on the Mac where it runs.

- It contains no analytics, telemetry, advertisements, or tracking.
- It makes no network requests.
- Region captures remain in memory and are copied to the system clipboard.
- The explicit **Save Current Screen to Desktop** action writes one PNG to the
  user's Desktop.
- It does not capture system audio, microphone audio, camera input, keystroke
  history, or clipboard history.

macOS requires Screen Recording permission because selecting a screenshot
requires reading display pixels. The permission can be revoked at any time in
**System Settings → Privacy & Security → Screen & System Audio Recording**.
